# Скрипт развёртывания PostgreSQL

`01_sberpi_schema.sql` создаёт полную структуру SberPI в одной пустой PostgreSQL-базе:

- бизнес-таблицы;
- таблицу аудита `audit_events`;
- `alembic_version` для основной цепочки миграций;
- `audit_alembic_version` для цепочки аудита.

Скрипт не создаёт сервер PostgreSQL, базу, роли и пароли. Эти объекты создаёт DBA по
правилам целевого контура. Скрипт следует выполнять владельцем пустой базы:

```bash
psql -v ON_ERROR_STOP=1 -d sberpi -f 01_sberpi_schema.sql
```

Проверенные версии после применения:

```text
alembic_version       = 20260807_0025
audit_alembic_version = 20260804_0001
```

Файл сформирован из реально развёрнутой схемы PostgreSQL 14.23 и повторно проверен на
отдельной чистой базе. В CI миграции также проверяются на PostgreSQL 16.
